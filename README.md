# frontend

Repozytorium strony [chilimango.pl](https://chilimango.pl) (Astro, wdrożenie z gałęzi `main`).

## Ochrona gałęzi `main`

Na `main` nie wolno pushować bezpośrednio — zmiany wchodzą wyłącznie przez pull request zatwierdzony przez właściciela repozytorium. Plik `CODEOWNERS` wymaga jego akceptacji przed merge. Reguły ochrony gałęzi (wymagany PR, wymagany check `ci`, brak force push i usuwania `main`) ustawia administrator repozytorium w ustawieniach GitHub; szczegóły są w planie wdrożenia (`docs/plans/chilimango-www-v2.md`, sekcja 9).
